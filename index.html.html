Self-Service Tableau Automation Tool
BNY Mellon — ECIF-UCM Data Migration Programme  ·  SG Analytics  ·  2022–2024
~100%

~70%

Problem Statement
  • During the BNY Mellon ECIF-UCM migration, stakeholders and business teams across multiple LOBs were submitting frequent ad hoc data requests — each requiring manual BA intervention to scope, query, and deliver.
  • The process created a bottleneck: every request needed dedicated SQL querying, cross-checking against the migration dataset, and manual delivery via email or spreadsheet — consuming hours per request.
  • With the migration running in parallel across legacy and target environments, the volume of data validation requests was escalating, stretching the BA team thin and slowing sprint velocity.
Solution Designed
  • Identified the recurring patterns in ad hoc requests and mapped the data model needed to serve 80%+ of all incoming query types without BA intervention.
  • Designed the tool's structure: built parameterized Tableau views connected directly to the underlying migration dataset (legacy + target), enabling stakeholders to apply filters and drill down independently.
  • Defined business rules and field mappings in collaboration with the data team — ensuring the tool surfaced accurate, reconciled data aligned to migration validation checkpoints.
  • Created user guidance documentation and conducted stakeholder walkthroughs to drive adoption across teams with varying technical proficiency.
Outcome: The tool was adopted by multiple LOB teams within the first sprint of launch. Ad hoc data requests to the BA team dropped significantly, freeing up capacity to focus on high-complexity migration analysis, API validation, and UAT coordination. The solution became a reference artefact cited in project retrospectives as a delivery efficiency win.
